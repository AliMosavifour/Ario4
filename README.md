# Ario (برنامه‌یار) — نسخهٔ وب و ویندوز

## آپلود روی گیت‌هاب (سایت رایگان با GitHub Pages)
1. در github.com یک مخزن (Repository) تازه بساز، مثلاً با نام `ario`.
2. همهٔ فایل‌های همین پوشه را داخل مخزن آپلود کن (Add file ← Upload files):
   `index.html`، `sw.js`، `manifest.webmanifest`، پوشهٔ `icons`، پوشهٔ `lib` و فایل `.nojekyll`.
   اگر فایل `.nojekyll` دیده نمی‌شود مهم نیست، بدون آن هم کار می‌کند.
3. به Settings ← Pages برو. در Source گزینهٔ «Deploy from a branch» و شاخهٔ `main` و پوشهٔ `/ (root)` را بزن و Save کن.
4. بعد از یکی دو دقیقه آدرس سایت نمایش داده می‌شود: `https://نام-کاربری.github.io/ario/`

## نصب روی ویندوز
با Chrome یا Edge آدرس سایت را باز کن. در نوار آدرس آیکون «نصب» (یا از منوی ⋮ گزینهٔ «Install Ario» / «Apps ← Install this site as an app») را بزن.
برنامه با آیکون خودش در منوی Start و دسک‌تاپ ساخته می‌شود و بدون اینترنت هم باز می‌شود.
روی اندروید و آیفون هم همین سایت را می‌شود به صفحهٔ اصلی اضافه کرد.

## نکته‌ها
- نصب‌شدن و کار کردن آفلاین فقط روی آدرس https (مثل GitHub Pages) فعال است. اگر `index.html` را مستقیم از روی کامپیوتر باز کنی، خود برنامه کار می‌کند ولی نصب و آفلاین نیست.
- اطلاعات هر کاربر روی همان مرورگر/دستگاه ذخیره می‌شود. از «حساب ← پشتیبان‌گیری و بازیابی» می‌شود آن را به دستگاه دیگر برد.
- بعد از هر نسخهٔ تازه، فایل‌ها را دوباره آپلود کن. کاربران نسخهٔ جدید را در بار بعدی باز کردن می‌بینند.
